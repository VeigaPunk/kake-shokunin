### P2 — Current freshness JSON can be truncated on a slow pipe

- **Class:** output-stream truncation from `process.exit()` immediately after output.
- **Evidence:** `/home/vgpnk/Projects/shokunin/kake-shokunin/scripts/freshness-sweep.mjs:1046-1061` calls `console.log(JSON.stringify(...))` and then `process.exit(v.code)`; the text-output path also exits at line 1075. The round-24 `paths-before.json` is 70,840 bytes. The historical local precedent is `/home/vgpnk/Projects/shokunin/kake-shokunin/.ufo/waves/round-21/anchor-census.mjs:540-541` and `anchors-fixed.json:2-3` (“stdout flush fix: exitCode not process.exit”). `/home/vgpnk/Projects/shokunin/kake-shokunin/scripts/corpus-contract.mjs:606-607` has the same emit-then-exit pattern, though I did not test that command's output size.
- **Exact probe commands and outputs** (stdout files were written only under `/tmp/kake-r24-ScoutMistakeSweep-Ydx2/`):

  ```text
  node --version
  v24.21.0

  node /home/vgpnk/Projects/shokunin/kake-shokunin/scripts/freshness-sweep.mjs --section=paths --json > /tmp/kake-r24-ScoutMistakeSweep-Ydx2/freshness-direct.json
  direct exit=1 bytes=70840
  python3 -m json.tool /tmp/kake-r24-ScoutMistakeSweep-Ydx2/freshness-direct.json >/dev/null
  direct JSON parse exit=0

  node /home/vgpnk/Projects/shokunin/kake-shokunin/scripts/freshness-sweep.mjs --section=paths --json | (sleep 1; cat > /tmp/kake-r24-ScoutMistakeSweep-Ydx2/freshness-slow-pipe.json)
  slow-pipe child exit=1 bytes=65536
  python3 -m json.tool /tmp/kake-r24-ScoutMistakeSweep-Ydx2/freshness-slow-pipe.json >/dev/null
  Unterminated string starting at: line 1868 column 7 (char 65495)
  slow-pipe JSON parse exit=1
  ```

  A synthetic control reproduced the exact boundary as well: `node -e "process.stdout.write('x'.repeat(200000)); process.exit(0)" | (sleep 1; wc -c)` printed `65536`.
- **Captured-by:** no lane-wide criterion. `/home/vgpnk/Projects/shokunin/kake-shokunin/corpus/QUALITY.md:112-114` requires the documented JSON output contract to cover every exit path, but does not require stream completion. The round-21 anchor-census change is a local precedent, not a general rule.
- **Impacted axis:** operability; downstream callers expecting JSON receive invalid JSON under a slow pipe reader, despite the tool's normal nonzero verdict exit.
- **Smallest fix:** replace output-path `process.exit(v.code)` calls with `process.exitCode = v.code` and return normally so Node drains stdout; add a regression that delays a pipe reader and parses the complete output.
