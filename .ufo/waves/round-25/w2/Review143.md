# Review 143 — WCAG 2.2 SC 1.4.3 Contrast (Minimum)

**Verdict: Disagree, narrowly.** The card’s identity fields are correct: id `1.4.3`, title `Contrast (Minimum)`, level `AA`, and the pinned SC anchor. `sourceQuote` is an exact substring of the extracted `normativeText` and of the saved criterion body; status is `not-assessed`. The 4.5:1 baseline and 3:1 large-scale threshold are accurate. The failure example is appropriate: 16px regular text is not large-scale, and `#999999` on `#FFFFFF` is approximately 2.85:1. The limitation correctly disclaims assessment and conformance. Two narrow omissions remain.

## Findings (by severity)

- **Moderate — Card fields: `publisherCheck` and `evidenceNeeded`** — exact substrings: “record the foreground color and the specified background it renders over in normal use” and “Record that the review covered both text color and background color being specified together.” The check asks the reviewer to record a foreground and specified background and calculate a ratio, but neither field says that having only one of those author-specified colors is itself a failure. That is an important missed outcome: the saved source’s linked definition `#dfn-contrast-ratio`, Note 4 (`source-wcag22.html`, lines 2893–2897), expressly makes it a failure when text color is specified without background color, and vice versa. Asking to record that the pair was reviewed does not state what to conclude when the pair is incomplete.
- **Minimal correction:** add to `publisherCheck` an explicit instruction: “If one of text/foreground color and background color is specified but the other is not, record a failure (contrast-ratio definition, Note 4).” The note’s white-background assumption in Note 3 must not be presented as curing the one-specified/one-unspecified failure.
- **Low — Card field: `publisherCheck`** — exact substring: “Exempt only text that is part of an inactive user interface component, pure decoration, not visible to anyone, part of a picture containing significant other visual content”. The criterion expressly applies these first four incidental exceptions to “Text or images of text” (`source-wcag22.html#contrast-minimum`, lines 806–807), while the card says only “text” immediately after distinguishing text from images of text. This can be read to require contrast for exempt images of text (for example, an image-of-text that is pure decoration). The separate logo/brand-name exception is text-only in the criterion, so keep that distinction.
- **Minimal correction:** phrase the first four exceptions as “text or images of text that are part of an inactive user interface component, are pure decoration, are not visible to anyone, or are part of a picture containing significant other visual content”; retain the logo/brand-name exception as text.
