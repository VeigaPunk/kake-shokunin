How to deploy Section titled “How to deploy” Create a render.com account and sign in Click the New + button from your dashboard and select Static Site Connect your GitHub or GitLab repository or alternatively enter the public URL of a public repository Give your website a name, select the branch and specify the build command and publish directory Build Command: npm run build Publish Directory: dist , for static sites; dist/client if you have any pages rendered on demand.
