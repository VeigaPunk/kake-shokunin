It means that links or records to this URL should be updated to the destination provided in the Location field of the server response. The 301 redirect is considered a best practice for upgrading users from HTTP to HTTPS . RFC 2616 [ 1 ] states that: If a client has link-editing capabilities, it should update all references to the Request URL. The response is cacheable unless indicated otherwise. Unless the request method was HEAD, the entity should contain a small hypertext note with a hyperlink to the new URL(s). If the 301 status code is received in response to a request of any type other than GET or HEAD, the client must ask the user before redirecting.
