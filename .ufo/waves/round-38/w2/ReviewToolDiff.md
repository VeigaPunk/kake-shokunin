Axes: **operability** attacked (robots audit validation); **freshness** not exercised or claimed (no web fetch; the target is local-only).

## Findings (severity order)

- **P3 — inherited URL-host lane reading is not honored.** `scripts/robots_audit.py:50-52` says URL validity is only http(s) plus a non-empty host and host syntax beyond non-emptiness is not judged. The check at `:525-530` accesses `parts.hostname`; `urlsplit` raises on a bracketed non-IPv6 host, caught as an invalid URL. With a valid robots file and URL `https://[not-ipv6]/p` (the character allow-list permits `[` and `]`, `:149`), the CLI returns exit 2 / `check_invalid`, rather than evaluating the non-empty host under that lane reading. The new (i) character check itself is exact; this is a carried-through URL parser restriction, not a regression introduced by the added regex. Evidence: `SCORECARD.md:1807-1810` and `scripts/robots_audit.py:50-52,513-531`; reproducer below. This finding is limited to the explicit lane reading; if “absolute URL” is intended to require a syntactically valid IP literal, that reading needs correction.

## Attacked statements and results

- **(h), including the 15-digit sentinel — holds.** `scripts/robots_audit.py:151-154,409-431,459-477`: tokens over 15 digits become a sentinel; `parse_constant` rejects NaN/Infinity/-Infinity and `load_manifest` maps that `ValueError` to one manifest fault. Probes covered all three constants, string `"NaN"`, 15- and 20-digit statuses, a long version, an unread 100-digit integer, negative long status, and raw JSON `1e400`; all matched their expected outcomes. A full 64 MiB manifest with a 64 MiB integer token completed in 0.112 s, clean/exit 0, under the declared 20 s bound.
- **(i), forbidden ASCII set — holds.** `scripts/robots_audit.py:144-149,508-531`: the regex rejects exactly 43 ASCII characters; exhaustive probe found no set difference or allowed-character false positive. The public v3 cases cover all 43 at six URL positions. Reproduction also exercised all 43 × 6 positions and 85 allowed ASCII characters: 258 invalid findings, 85 checks evaluated. Non-ASCII and malformed `%` escapes were accepted as the contract says.
- **(k), normalize-before-compare — holds.** `scripts/robots_audit.py:174-202,242-245,534-539,598-609`: path is normalized before the exact `/robots.txt` comparison and the same normalized path is passed to `decide`; rule values are normalized at parse time. Probes covered bare path despite explicit disallow, `%2E`/`%72` decoding, case, query, empty query, fragment stripping, trailing slash, reserved `%2F`, and 404/503 precedence; all matched the contract.
- **Round-37 docstring/contract readings — holds except the P3 host-syntax item above.** Probes confirmed uppercase scheme, BOM manifest fault, and `*` user-agent fault per the documented readings. No other mismatch found in the attacked hunks.
