# C1 matrix runner

Axis: operability.

## Implementation

Added `.ufo/waves/round-45/c45_matrix.py`. It selects frozen v1 for `--stage before` and v2 for `--stage after`; runs each available fixture (`controls.tsv` + `fake_counter.py`) into a separate cohort; runs the one-row honest control with the frozen counter; and records driver summaries, captured output, missing prerequisites, and verdicts in `verification/matrix/<stage>.json`. The stale-planted before case copies the fixture's planted receipt bytes into its isolated run cohort. After-stage rejection classes are extracted from actual rejected control/build rows, not inferred from fixture names. `--with-honest` only reads the committed regression receipt; it never launches the heavy regression.
