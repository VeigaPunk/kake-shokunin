- Finding (minor): P02 is partly true: S078 requires the well-known path when both files exist, but neither S078 nor S079 requires the root file to be a redirect or byte copy. P08 is partly true: preference among Contact lines is supported; "Contact first" is ambiguous, and if it asserts required field placement, the RFC says field order is unimportant (it does not forbid an editorial recommendation). Other directly checked claims P01, P03-P07, P09-P11 and P12's branch claims are true. P12's artifact claims have the direct-source gap below.

  = RFC "domain or IP address in the URI used to retrieve it". Both equivalent, not overstated.
