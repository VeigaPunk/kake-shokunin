## TIGHTENINGS:

- **T1 — Freeze per-member argv templates in contract.json** (the single authority): `members[] = {path, argv_template, allowed_env}`; the counted command must equal the template modulo the five placeholders, else a new `command_shape` mismatch. Required in every template: argv = `[python3, <py-opts>, m.path, args...]` with m.path the script operand; `--root` must be `.` or `<scratch>`-derived; the revision placeholder must reach the member. Allowed env prefix: `TMPDIR=<scratch>` only. Kills C1–C7 (incl. `--selftest`, `--base T`, literal revs, env hijack, `|| true`) and makes C6's bracket rule moot.
- **T2 — Exec semantics.** Run `execve(shlex'd argv)` with env = `{PATH=<fixed system>, TMPDIR, HOME=<scratch>, LANG=C}` (all `GIT_*`, `PYTHON*`, `KAKE_*` scrubbed whether inherited or assigned); `python3` resolved to an absolute interpreter (`sys.executable`), never via env PATH. Kills C3/C7.
- **T3 — Population identity, not count.** contract.json carries the 28 literal paths AND each member's base blob sha256; counter asserts set equality (else `member_set_changed`) and each path is a regular blob at T (else `member_not_blob`); optionally `member_changed` when blob sha differs from base (or record it in `--json` for reviewer check). Kills C8/C9.
- **T4 — `never met` needs a real not-met.** Pin must be a *strict* ancestor of T at which the member file existed (ls-tree check → else `pin_member_absent`), e_T must == 1 and e_P must == 1 (usage/unevaluable/timeout ≠ measured not-met → `never_met_unmeasured`). Kills C10, C17-abuse.
- **T5 — `historical` pin provenance.** Pin must equal the member's declared measured revision — contract.json `pins{member: hex}` (sourced from each counter's own receipt/`verified-at`), not "first hex in the cell"; e_P==0 AND e_T==1 exactly (else `historical_unmeasured_red`). Kills C11, C12.
- **T6 — Closed label enum.** Kind cell visible text (code spans and comments stripped, ASCII-only) must match `^gate( \(historical pin:[0-9a-f]{40}\)| \(never met pin:[0-9a-f]{40}\))?$`; anything else → `label_invalid` (never silently `live`). Kills C13, C20.
- **T7 — Row visibility + global uniqueness.** Fix the dialect (CommonMark: backtick+tilde fences, indented code, HTML comments); cells split with `\|` honored, exactly 8 non-empty cells. Uniqueness scan: a member path appearing in *any* table row of *any* table (conforming or not), comments/fences excluded, must be that member's unique counted row → else `hidden_row`/`duplicate_row`. Kills C14, C15, C19.
- **T8 — `scores_held` precision.** SKILL.md/SCORECARD.md read via `git cat-file` at `--revision` only; exactly one axis table (else unevaluable); exactly one row per axis name (exact trimmed casefold match → else `axis_row_ambiguous`); Score cell normalized (strip `**`/backticks) must equal `10`/`10`/`2` digit-exact. Kills C16.
- **T9 — Receipt binds the run.** Counter prints (and receipts must record) `--root` toplevel, `rev-parse --verify <rev>`, `merge-base --is-ancestor <rev> master`; w2 reviewers re-run on the canonical lane. Mitigates C18 (process, not rule).
- **T10 — If argv templates aren't frozen**, fix the bracket rule: a kept `[...]` must contain ≥1 recognized `<...>`; zero-placeholder segments are dropped. Residual cover for C6 only.

Predicate-level note (for the L1, not a rule): the contract binds labels to *exit codes* of an attacker-shaped command — a member printing `met=False` yet exiting 0 counts as green. T1 shrinks this to "exit 0 under the declared command," which is the honest reading; anything weaker (C1–C7 open) makes `mismatches==0` certify nothing.

## VERDICT:

The C1 rules as written are defeated end-to-end: the cheapest full sweep is all-rows `live` + `--selftest` commands (C1; also wrapper/env/`--root` variants C2–C4) or surgical `never met`+absent-pin relabels of red members (C10) — none is a counted mismatch, and `members==28` survives even member deletion/re-add (C9) or member-blob edits (C8) because the predicate counts paths, not identity. Minimum viable fix is T1+T3+T4 (frozen argv templates, frozen member set+blob pins, real not-met for `never met`); T5–T8 close the provenance and parser-ambiguity holes w2 would otherwise spend the wave rediscovering.
