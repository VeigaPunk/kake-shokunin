# CriticC2Semantics

## Scope and evidence

Axes attacked: **operability / header-rule fidelity** (does each class catch what its cited source supports?), and **measurement robustness** (does the frozen H1–H18 counter exercise that edge?). Read round-61 contract and A4, the frozen `scripts/header_audit.py` and `c61_header_cases.py`, the C2 entry, all 12 response receipts, and retained S430–S433 bodies. SHA-256 and byte counts in `sources/receipts.json` match the four retained source bodies. The capture manifest binds 12 checks to 12 existing receipts; captured statuses are 200 or 404. Running the frozen audit on that manifest yielded `checks=12 findings=13`, exit 1; that is the contract's recorded, non-asserted-clean R3 shape, not a C2 failure.

## Cross-cutting edge checks

- **Empty / OWS-only values:** confirmed tool output: CT, HSTS and CSP all exit 0 on empty/OWS-only field values; XCTO empty exits 1. Frozen H17 tests whitespace surrounding *non-empty* values, not whitespace-only values, so it does not close this gap.
- **Missing vs false flags:** explicit false and absent expectation flags both suppress the relevant check, per the tool's documented manifest semantics. This is not a tool mismatch, but it means absence is not an assertion of compliance. The important mismatch is XCTO `true` plus absent field still clean. `https` is taken from the manifest/URL, not cross-checked against the response's `finalUrl`; it is an asserted expectation input, not capture-derived fact.
- **Duplicate case / OWS:** duplicate `Content-Type` / `content-type` is detected. Values trim only SP and HTAB, matching RFC OWS; field names are not trimmed and invalid names generate `field_name_syntax` (a leading-space name also fails field-name matching). No false result in these tested boundaries.
- **2xx boundary:** 204 and 205 are false reds for the source's content-scoped rule. 206 and 299 are flagged when CT is absent; 300 is clean. The inclusive numeric 2xx test matches the frozen wording but misses the no-content 204/205 exceptions.

## Verdict

**C2 semantics are not fully source-faithful.** Confirmed false greens: empty/OWS-only CT, HSTS, CSP; absent XCTO despite `xcto_nosniff_value: true`. Confirmed false red: missing CT on 204 (and 205). Frozen H2 explicitly enshrines the 204 false red; H17 does not test empty values. Singleton case-folding and field-name syntax behaved as specified. These are defects in the declared policy/counter expectations, not evidence that the frozen tool misimplements its literal rules. Smallest safe correction is a versioned tightening with focused fixtures for empty values, absent XCTO, and 204/205; do not alter the frozen predicate/tool silently.

VERDICT: REJECT C2 as source-faithful as written; accept the literal audit mechanics for singleton and field-name syntax. Empty/absent policy values false-green; content-type on 204/205 false-red.
