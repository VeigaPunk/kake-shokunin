D1 attack-floor arithmetic for the round-83 population (14 seats, 5 attack-role)

Counter rule (c83_defect_queue.py derive_population/item_d1):
  settled      = results rows whose output is a non-empty string
  settled_share= round(len(settled_attack)/settled, 4)
  pass         = settled_attack >= 2  AND  settled_share >= 0.25
The accounting's "settled", "settled_names" (sorted), "settled_attack" and
"settled_share" must equal the counter's own derivation exactly.

store the same round(x, 4) value the counter computes (e.g. 3/12 -> 0.25,
4/14 -> 0.2857), not a differently-rounded or string value.
