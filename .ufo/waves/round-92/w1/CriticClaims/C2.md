## 3. The reference contradicts the contract (frozen-instrument defect, routed)

Contract clause 4: "A delta-seconds argument (`max-age`, `s-maxage`) must be a bare non-negative
decimal integer: a quoted or signed form is a refusal."

Counter reference, lines 86–88: `if len(arg) >= 2 and arg[0] == '"' and arg[-1] == '"': arg =
arg[1:-1]`, then `if name in DELTA and not re.fullmatch(r"[0-9]+", arg)` — the quotes are stripped
**before** the digit test, so the quoted form is accepted:

```
quoted delta max-age="120" -> {"decision": "explicit", "heuristic": false, "lifetime": 120}
signed delta max-age=+5    -> invalid_input: delta-seconds argument is not a bare non-negative integer
```

No hand case and no generated case uses a quoted delta, so the drift is invisible to the score:
a contract-faithful subject (F4 refuses it) and a reference-faithful subject both read
`met=true`. The counter's pre-score reference self-check (which exits 2 on drift) therefore
cannot catch it — it checks the reference against the hand cases, and the hand cases are silent
here. **C2-D1.**

Honest verdict for the axis: the instrument is a **case-agreement** test over a fixed, public
population, plus a sandbox that genuinely blocks the oracle-import and pin-reader forgeries. It is
not a conformance test. A passing subject may be a lookup table; the claim should be worded as
"a subject agrees with the counter's reference on the declared population and is not the oracle",
never as "the capability is implemented".
