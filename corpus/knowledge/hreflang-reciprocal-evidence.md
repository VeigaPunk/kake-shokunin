## Manual publisher decision aid

First distinguish a complete metadata set from a partial or absent capture. An
unseen return is unknown, not a demonstrated missing link. For each supplied pair,
record both directions, self links and URL form separately. Propose the specific
source edit only where evidence establishes a defect; otherwise request the missing
complete metadata. Evaluate optional fallback against publisher needs separately.

The authored exercise `.ufo/waves/round-70/author/decision-memo.md` applies these
steps to synthetic metadata. Its oracle was public. It establishes no automation,
blind generalization, actual served state, crawling, canonical selection or indexing.
No promotion or numeric calibration lift follows. This card is Google-specific
published guidance, not a claim that every search engine implements these rules.
